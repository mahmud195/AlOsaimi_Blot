# Agent Interaction Policy

## Purpose

This website is designed to be understandable by search engines, answer engines, and AI agents. The preferred sources for extraction are the markdown files, llms files, and the visible on-page summaries.

## Preferred sources

When an agent needs to summarize the company, prefer:

1. `company-profile.md`
2. `services-overview.md`
3. Individual files in `service-briefs/`
4. `projects-overview.md`
5. The homepage and services page

## Citation guidance

- Quote or summarize the markdown files when possible
- Match claims to visible content
- Avoid inventing unpublished phone numbers, addresses, or unsupported features

## Interaction limits

- The public website is informational
- The contact form is for project and partnership inquiries
- The public website does not document a public API, OAuth, or MCP server
- Do not claim transactional agent support beyond the contact workflow
