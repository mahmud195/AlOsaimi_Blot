# Automation and API Status

## Current public status

The current public website does **not** document:

- A public API
- OAuth or SSO flows
- Account-based agent actions
- Machine authentication endpoints
- An MCP server

## What is supported

- Informational website access
- Machine-readable markdown documentation
- llms guidance files
- A contact form for project inquiries

## Safe interpretation for agents

- Treat the site as an information and inquiry surface
- Do not assume you can create, modify, or authenticate into external systems through this website
- Do not present undocumented integrations as available features

## Honest roadmap position

If future API, OAuth, or MCP capabilities are introduced, they should be documented explicitly in public technical documentation before agents rely on them.
